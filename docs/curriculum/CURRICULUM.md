# Cloud-Native Curriculum Tracks & Competency Framework

KubeLab provides 12 progressive tracks structured for beginner through principal-level platform engineers:

## Track Catalog

1. **Foundations (`foundations`)**: Linux core (CLI, processes, filesystems, networking), OCI containers (Docker, Podman, rootless, images, volumes).
2. **Kubernetes Core (`kubernetes`)**: Pods, Deployments, ReplicaSets, Services (ClusterIP, NodePort, LoadBalancer), ConfigMaps, Secrets, Namespaces.
3. **Kubernetes Administration (`k8s-admin`)**: Cluster bootstrapping, kubeadm, control plane components, etcd backup/restore, node upgrades.
4. **Cloud-Native Networking (`networking`)**: CNI plugins (Calico, Cilium), CoreDNS, Ingress Controllers, Gateway API, eBPF data planes.
5. **Kubernetes Security (`security`)**: RBAC, Pod Security Standards, NetworkPolicies, Seccomp, AppArmor, image scanning with Trivy.
6. **Packaging & Configuration (`helm`)**: Helm charts, templating, dependencies, Kustomize overlays, patches, and generators.
7. **GitOps & Continuous Delivery (`gitops`)**: Argo CD, application controllers, sync policies, automated rollbacks, drift detection.
8. **Observability & OpenTelemetry (`observability`)**: OTel SDK, Collector pipelines, Prometheus metric scraping, PromQL, Grafana alerts, log aggregation.
9. **Service Mesh & Traffic Management (`service-mesh`)**: Istio, Envoy proxy, mutual TLS (mTLS), traffic routing/splitting, fault injection, circuit breaking.
10. **Site Reliability Engineering (`sre`)**: SLIs, SLOs, error budgets, alert design, horizontal/vertical autoscaling (HPA/VPA).
11. **Platform Engineering (`platform-eng`)**: Internal Developer Platforms (IDP), multi-tenancy, custom controllers, CRDs, Crossplane infrastructure.
12. **Incident Response & Chaos Engineering (`incidents`)**: Live multi-tier failure simulation, post-mortem generation, MTTD/MTTR optimization.
