# Curriculum Structure & Tracks

KubeLab offers 15 tracks with 145 progressive hands-on labs:
1. Linux & Containers (8 labs)
2. Kubernetes Core (15 labs)
3. Storage & PVs (8 labs)
4. Cloud-Native Networking (13 labs)
5. Helm & Kustomize (8 labs)
6. Cluster Administration (12 labs)
7. Zero-Trust Security (13 labs)
8. GitOps with Argo CD (11 labs)
9. Service Mesh with Istio (11 labs)
10. Observability (10 labs)
11. Troubleshooting (10 labs)
12. SRE & Performance (8 labs)
13. Platform Engineering (7 labs)
14. Production Incidents (10 labs)
15. Certification Drills (10 labs)
